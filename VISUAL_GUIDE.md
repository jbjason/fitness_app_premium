## 📱 Navigation Flow

```
App Launch
    ↓
Splash Screen
    ↓
Onboarding
    ├── Select Gender
    ├── Choose Plan Level (Beginner/Intermediate/Advanced)
    ├── Set Target Goal
    ├── Enter Height
    ├── Enter Current Weight
    └── Enter Target Weight
    ↓
Home Screen
    ├── View Weight Loss Banner
    │   ↓
    │   Tap Banner
    │   ↓
    │   Weight Loss Plan Screen
    │       ├── View Beginner Tab
    │       ├── View Intermediate Tab
    │       └── View Advanced Tab
    │
    └── Navigate to Profile
        ↓
        Profile Screen
        ↓
        Tap "Weight Loss Plan"
        ↓
        Weight Loss Plan Screen
```

## 💾 Data Structure

```dart
WeightLossPlan
    ├── level: PlanLevel (enum)
    ├── weeklyWeightLoss: double
    ├── dailyCalorieDeficit: double
    ├── drinkPlan: DrinkPlan
    │   ├── waterLiters: String
    │   ├── greenTea: String
    │   ├── blackCoffee: String
    │   └── optional: String
    ├── mealPlan: MealPlan
    │   ├── breakfast: String
    │   ├── lunch: String
    │   ├── dinner: String
    │   └── snacks: String
    ├── exercisePlan: ExercisePlan
    │   ├── duration: String
    │   └── activities: List<String>
    └── lifestylePlan: LifestylePlan
        ├── sleepHours: String
        ├── dailySteps: int
        └── cheatMealsPerWeek: int
```

## 🔄 State Management

```
OnboardProvider (ChangeNotifier)
    │
    ├── selectedPlan: int (0=Beginner, 1=Intermediate, 2=Advanced)
    ├── selectedWeight: double
    ├── selectedTargetWeight: double
    │
    ├── currentPlanLevel: PlanLevel (computed)
    └── currentWeightLossPlan: WeightLossPlan (computed)
        │
        └── Provides data to all UI components
```

## 📐 Responsive Design

All measurements use `flutter_screenutil`:
- `.w` - Width responsive
- `.h` - Height responsive
- `.sp` - Font size responsive
- `.r` - Radius responsive

Perfect scaling across all device sizes!
